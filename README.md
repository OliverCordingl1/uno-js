# UnoJS

A Typescript implementation of the **Uno!** card game.

## Current Features:

- Number cards, which can have a number from 0-9, and a colour (Red, Blue, Green, Yellow)
- Multiplayer functionality, with turns.
- Working deck of cards

## How to run

After cloning this repository, it is super easy to get running.

```bash
cd uno
npm ci
npm run start:dev # Runs on http://localhost:1234/
```

This project is currently built with Parcel for simplicity.
